# DJI Mavic 4 Pro | Product Page

A responsive drone product page built with HTML and CSS only (Flexbox, Grid and media queries).

## Sections

- Navbar and product hero
- Comparison table
- Rating and customer reviews
- Related products
- Footer

## Project Structure

```
├── index.html
├── CSS/
│   ├── style.css         # base (desktop) styles
│   └── responsive.css    # media queries
└── Images/
    └── Icons/
```

## Getting Started

Open `index.html` in any modern browser.

## Responsive Breakpoints

| Screen width | Main changes |
|---|---|
| Above 1100px | Two-column hero and reviews, 4 products per row |
| 1100px and below | Hero and reviews stack, 2 products per row |
| 767px and below | One column, navbar links hidden |
| 480px and below | Smaller text and spacing |

The comparison table scrolls horizontally on small screens.

## Note

This is a front-end practice project. Buttons and footer links are placeholders.
